# Employment

**Primary sources:** LEHD/QCEW-based jobs CSV, REMI employment model exports  
**Build scripts:** `forecast_controls/Emp_controls.py`, `forecast_controls/emp_controls_v2.py`

This domain covers the base-year job inventory, annual employment growth control totals, job relocation rates, building capacity parameters, and employment sector definitions.

## `jobs`

Base-year job inventory. One row per job — **not per establishment**. Every job must be assigned to a building.

**Index:** `job_id` (unique)  
**Source:** CSV file — path configured in `config/files.yaml`

| Column | Type | Rules | Notes |
|---|---|---|---|
| `job_id` | int32 | unique, no null | |
| `building_id` | int32 | join → `buildings`, no null | -1 = unplaced (assigned to pseudo-building at startup) |
| `sector_id` | int8 | values: 1–18, no null | Employment sector |
| `home_based_status` | int8 | values: 0, 1 | 0=non-home-based, 1=home-based |
| `sqft` | int16 | no null | Square footage per job |

**Home-based jobs** (value = 1) are located in residential buildings. Non-home-based jobs are in commercial/industrial buildings.

**Common issues:**
- `building_id = -1` — unplaced jobs; should be minimal in base year; assigned to pseudo-buildings at startup
- `sector_id` outside 1–18 — check against SEMCOG sector mapping
- `building_id` referencing non-existent buildings — re-geocode or assign to nearest valid building

## `annual_employment_control_totals`

Target job counts by large area × sector × home-based status × year. The `jobs_transition` step uses this to add or remove jobs annually.

**Index:** Multi-index `(year, sector_id, home_based_status)`  
**Source:** CSV — path in `config/files.yaml`  
**Generated by:** `forecast_controls/Emp_controls.py` or `emp_controls_v2.py`

| Column | Type | Allowed Values | Notes |
|---|---|---|---|
| `year` | int16 | all forecast years | Part of multi-index |
| `sector_id` | int8 | 1–18 | Part of multi-index |
| `home_based_status` | int8 | 0, 1 | Part of multi-index |
| `large_area_id` | int16 | 8 valid codes | |
| `total_number_of_jobs` | int32 | no null | Target job count |

**Important:** All combinations of year × sector × large area × home-based status must be present for all forecast years. Missing cells cause the transition model to skip that segment entirely.

**Common issues:**
- Missing sector/year combinations — model will not grow/shrink those jobs
- REMI sector codes differ from SEMCOG 18-sector classification — apply the sector crosswalk before generating controls (see `forecast_controls/data/` for the mapping file)

## `building_sqft_per_job`

Space required per job by building type. Used to compute building job capacity (`job_spaces = non_residential_sqft / sqft_per_job`).

**Index:** `building_type_id` (unique)  
**Source:** CSV — path in `config/files.yaml`

| Column | Type | Notes |
|---|---|---|
| `building_type_id` | int8 | Must cover all non-residential building types |
| `building_sqft_per_job` | int16 | Sq ft per job (typical range: 225–1000) |

Typical values: Office (~300), Retail (~400), Industrial (~550–700), Medical (~225), Institutional (~600).

## `employed_workers_rate`

Expected number of employed workers by age group and large area. Used by the `fix_lpr` simulation step to adjust the `workers` count in the households table after each year's household transition, ensuring the simulated workforce matches employment targets.

**Index:** `large_area_id`  
**Source:** CSV — path in `config/files.yaml`

| Column | Type | Notes |
|---|---|---|
| `large_area_id` | int16 | 8 valid large area codes |
| `age_min/max` | int8 | Age group bounds |
| (rate columns) | float | Expected employed workers for each age group |

**Update:** Derive from REMI employment forecasts by large area and age group. Update when new REMI runs are available or when the age group structure changes.

## Update Checklist (New Forecast Cycle)

- [ ] Get new REMI employment export by large area × REMI sector × year
- [ ] Apply REMI-to-SEMCOG sector crosswalk (file in `forecast_controls/data/`)
- [ ] Run employment controls script to generate `annual_employment_control_totals.csv`
- [ ] Update `jobs.csv` if base year changes — pull from LEHD/QCEW geocoded to buildings
- [ ] Verify all 18 sectors × 8 large areas × 2 home-based statuses × all forecast years are covered
- [ ] Cross-check: sum of `total_number_of_jobs` for base year ≈ total rows in `jobs`
- [ ] Update `employed_workers_rate` from latest REMI employment data by age group and large area
- [ ] Run validation: `python -m input_validation.cli --hdf <output hdf>`
