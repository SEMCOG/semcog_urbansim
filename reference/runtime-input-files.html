    Runtime Input Files¶

    This page lists the file-level inputs required by the current forward forecast. It intentionally names files and their roles without prescribing their storage locations. The main HDF contains the assembled data tables documented in the Table Catalog.

    Core data and networks¶

    File Role and notes
    main_{date}.h5 Primary forecast input HDF. It contains base-year agents, geography, controls, events, and model-support tables. It also contains the 2015 and 2020 TAZ trend bases used by the household location model; separate historical HDF files are not required.
    access_indicators.h5 Precomputed parcel accessibility metrics for walk, bike, and drive travel.
    semcog_networks.h5 Pandana network bundle used to construct the walk, bike, and drive networks at startup.

    Location-choice model artifacts¶

    File or file set Role and notes
    model_description.yaml HLCM and ELCM model package manifests.
    shap_scores.yaml HLCM feature-importance metadata.
    *.pt Trained location-choice model artifacts: 96 HLCM and 192 ELCM models.
    config.yaml Configuration for each residential and non-residential price model.
    metadata.pkl REPM feature and model metadata.
    summary.yaml REPM estimation summary.
    xgb_model.json Trained XGBoost REPM model. The current forecast registers 64 of these models.

    Simulation configuration¶

    File Role and notes
    yaml_configs_elcm_hlcm.yaml Selects and configures the HLCM and ELCM model sets.
    model_structure.yaml Defines model categories and attributes.
    available_networks_2050.yaml Defines network names available to the forecast.
    networks_walk.yaml Walk-network accessibility definitions.
    networks_drv.yaml Drive-network accessibility definitions.
    demolition_model.yaml Demolition model configuration.
    res_developer.yaml Residential developer model configuration.
    nonres_developer.yaml Non-residential developer model configuration.
    proforma.yaml Development feasibility (pro forma) parameters.
    cost_shifters.yaml Construction-cost adjustment parameters.
    developer_selection_coefs.yaml Developer project-selection coefficients.

    Indicator post-processing inputs are intentionally excluded from this inventory.
